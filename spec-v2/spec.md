## 2. Назначение и аудитория

MyGenoTree — web-приложение для создания, просмотра и редактирования частных генеалогических деревьев.

Основная аудитория MVP — обычные пользователи без опыта работы с профессиональными генеалогическими программами. Интерфейс должен объяснять действия простыми пользовательскими терминами и не требовать знания структуры графов или специальных генеалогических форматов.

## 3. Границы MVP

MVP является локальным HTTPS-прототипом. Он должен полностью запускаться на `localhost` через Docker Compose и позволять проверить все описанные пользовательские и API-сценарии.

MVP не является production-сервисом. Требования к внешнему размещению, SLA, резервному копированию, production-мониторингу и публичной эксплуатации приведены как явно отложенные в [документе о качестве](quality.md).

Функциональные требования описаны в [mvp.md](mvp.md). Возможности, которые не реализуются в MVP, но должны учитываться архитектурой, перечислены в [future.md](future.md).

## 4. Архитектура

Приложение разделяется на:

- backend;
- frontend;
- PostgreSQL;
- локальное файловое хранилище, доступное через абстракцию Flysystem;
- HTTPS reverse proxy.

Frontend и backend взаимодействуют только через REST/JSON API. API проектируется так, чтобы в дальнейшем его мог использовать мобильный клиент.

Frontend и API доступны с одного origin. API размещается под префиксом `/api/v1`.

## 5. Технологический стек

### Backend

- PHP 8.5;
- Symfony 8.1, последний доступный patch-релиз ветки 8.1;
- Doctrine ORM;
- Doctrine Migrations;
- Flysystem;
- PostgreSQL 18, последний доступный patch-релиз ветки 18.

Symfony 8.1 требует PHP 8.4 или новее, поэтому PHP 8.5 является допустимой версией. При разработке нужно учитывать окончание поддержки Symfony 8.1 и не блокировать обновление на следующую поддерживаемую ветку.

Официальные источники:

- [Symfony 8.1](https://symfony.com/releases/8.1);
- [политика версий PostgreSQL](https://www.postgresql.org/support/versioning/).

### Frontend

- React или Vue.js по выбору исполнителя;
- strict TypeScript;
- Node.js 24 LTS, последний доступный patch-релиз ветки 24;
- типы API должны генерироваться из OpenAPI либо автоматически проверяться на соответствие OpenAPI.

Выбор React или Vue.js не должен менять пользовательские возможности и критерии приёмки.

Официальный источник: [линии выпусков Node.js](https://nodejs.org/en/about/previous-releases).

## 7. Термины

- **Владелец** — пользователь, создавший дерево.
- **Дерево** — именованный связный граф персон и отношений одного владельца.
- **Персона** — человек, описанный внутри одного дерева.
- **Родительская связь** — направленная кровная связь от отца или матери к ребёнку.
- **Период брака** — одна запись о браке двух персон с датами заключения и расторжения.
- **Семейный блок** — представление одного партнёра, всех периодов брака с ним и общих детей.
- **Автоматическое событие** — событие, управляемое исходной персоной или связью.
- **Ручное событие** — событие, которое пользователь создаёт и изменяет самостоятельно.
- **Неизвестное значение** — осознанно указанное отсутствие сведений; оно отличается от неприменимого или отсутствующего поля.
- **Snapshot дерева** — компактное согласованное представление персон, связей, опоры и состояния силовой карты одной версии дерева.
