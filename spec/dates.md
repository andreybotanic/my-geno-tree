# Даты

Любая дата может быть приблизительной, если точная дата не известна.
Дата может быть указана без конкретного числа и даже без указания месяца.
Если задается только год, то должен появляться чекбокс "приблизительно", означающий, что год указан не точно.

## Примеры дат
- полная дата: 25.10.1994 г.
- дата без числа: октябрь 1994 года
- год: 1994 год
- год приблизительно: примерно 1994 год
