# Техническое задание на разработку web-приложения MyGenoTree

Данная документация является основной и не предназначена для редактирования.

## Общее описание продукта

MyGenoTree - web-приложение для создания и отображения генеалогических деревьев.
Продукт должен представлять собой web-приложение, разделенное на две части:
- бэкенд,
- фронтенд.

Фронтенд и бэкенд должны взаимодействовать между собой по API, чтобы в дальнейшем была возможность создания мобильного приложения,
которое будет использовать тот же самый бэкенд.

## Технологический стек

Бэкенд:
- основа приложения: PHP 8.5 + Symfony 8.1
- реляционная БД: PostgreSQL

Фронтенд: Vue.js или React.
